昔前朝季有怪焉，其状无形，本潜于竹林之一清风也。日与斑竹相狎，目不识丁，绝不知人世何物。

时有生客误入，风动竹啸，哗哗然作鬼泣，客褫魄而遁，风犹晏然未觉其怖也。

后忽天狗食日，甲兵四起，乾坤倾覆。贼军举火，百里竹林化为焦土。

风失其所，性遂大异，化作阴厉妖风，狂突乱奔，搅得一方地府乌烟，阴气割骨，旱涝频仍。时生民哀号连野，妖风懵懂，不知悲音何意，徒随之怒号而已。

逮后朝定鼎，故土暂宁，妖风执念渐消，余息将绝，竟委蜕为初时细细一小风。风流落近村牛牢，窥见一稚童蜷牛腹下窃读。风暗骇曰：「此何等厌胜邪物，竟能摄人魂魄？」待童子受唤，藏书于槽下，风乘隙趋视，乃『道可道，非常道』之谰言魔文也。怪阵迷光，绕之不明，吓得妖风溃散而逃。然逃之虽远，其妖字竟如锁链缠身，百思不解，而痴根已种。乃随波逐流入中州繁华地，触目皆令人汗毛倒竖之晦涩经卷。风左躲右闪，跌跌撞撞，谁料反惹得酸儒举子满腹墨沈，尽溷其身，终一日字重如山，风不堪其压，真灵欲碎，奄奄将散。俄尔天机乍泄，满身符箓魔文竟自生经纬，结作皮囊，化出一似人非人之物。

自此，此风游荡九州，历劫易代，遍吸琅嬛阁中之气。久之，竟晓人语，能吟哦，亦通七情六欲。常附竹简败纸，乘文人假寐之机，潜夺其笔，广播奇闻。初时道行浅薄，满纸癫狂，每作淫辞秽语、伤风败俗之邪文。后遇一穷酸骨梗之士，见之大怒，提笔疾书千言，痛陈礼义廉耻、忠孝仁德以镇之。风中其咒，骇然而惧，遂改前非，转以播弄文明、广传格物之学以赚取功德。积年累月，竟自坤转乾，形神俱隐。除却修真羽客、体弱阴虚之人与黄口小儿，凡眼莫能视也。知无不知，言无不尽。世人讹传，称其乃文昌帝君座下大逆不道之童子谪降领罚。呸！实乃一介山野妖风，横遭人世浊墨奸污耳！今兹世道，它将那人间污秽越聚越多，反育出一点贼智，狡黠如书童，强作天真烂漫之态。其偶发胡言，早脱昔年兽性之蛮荒，尽作庙堂之上腐臭之官腔也。若此风有知，明其所抗衡者何物，必信袞袞诸公大人之浊气，真乃冢中枯骨之尸臭也！哀哉异哉！
